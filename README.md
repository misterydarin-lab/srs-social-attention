# SRS Social Attention

A personal, non-commercial, read-only research tool for measuring
aggregate public discussion activity around semiconductor companies
and AI infrastructure topics.

The application is designed to measure aggregate indicators such as:

- relevant post activity
- comment activity
- changes in discussion activity over time
- semiconductor and AI infrastructure topic activity

The application does not post, comment, vote, or message Reddit users.

It does not profile individual Reddit users, infer sensitive user
characteristics, train AI/ML models on Reddit content, or redistribute
Reddit content.

The resulting aggregate metrics are used privately as one input in a
personal investment research system.
